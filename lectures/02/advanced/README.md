## Data

- `glossary_sft.jsonl`: 116 unchanged records generated by the course script from all 58 glossary entries.
- `train.jsonl`: those 116 questions/definitions transformed into the course JSON answer format, plus 8 questions about unlisted terms (124 records).
- `valid.jsonl`: 8 known-term and 4 unlisted-term questions (12 records).
- `test.jsonl`: 6 named-term, 6 paraphrased, and 6 unlisted-term questions (18 records).
- `gold.json`: reference definitions, coverage flags, and keyword groups; never supplied to the answering model.
- `advanced_glossary.py`: standard-library data preparation, scoring, and a simple lexical lookup baseline.
- `manifest.json`: source revision, transformations, evaluation limitations, and file hashes.

The model is tested closed book. The lookup baseline can access the source glossary, which is the defining difference between these two approaches. No prompt contains the glossary definitions during neural-model evaluation.

Known concepts occur in both training and testing, but questions do not overlap. Unknown terms are disjoint across training, validation, and testing. “Unknown” means unlisted in this course glossary; a correct real-world definition can still violate the task's required coverage policy. Content scores are keyword proxies, so inspect the exported raw answers manually.

The first experiment fixes three epochs instead of the original FAQ experiment's twenty: the dataset is larger (124 vs 14 records).
